## Cómo usar los prompts en Flow

1. Abre [Google Flow](https://labs.google/flow) o Gemini Image (`gemini-3.1-flash-image`).
2. Copia un bloque completo de [`docs/prompts-flow-melia.md`](docs/prompts-flow-melia.md) (incluye paleta y reglas).
3. Genera en ratio 1:1, 4:5 o 9:16 según el prompt.
4. Si el texto sale mal: pide *“mismo diseño, tipografía nítida, texto exacto: …”*.
5. Para producto real: sube una foto tuya y pide edición al estilo Melia.

**Paleta rápida:** `#625A99` (púrpura) · `#FCB4B4` (rosa) · `#f85477` (CTA) · `#FEF271` (acento).
